# アルバイト勤怠管理アプリ

タブレット1台で完結する打刻アプリ。詳細な要件は [勤怠管理アプリ_要件定義.md](./勤怠管理アプリ_要件定義.md) を参照。

- サーバー: Node.js (>=22.5) + Express。DB は Node 標準の `node:sqlite`（ネイティブビルド不要）
- 依存パッケージ: `express` `express-session` `bcryptjs` のみ（すべて Pure JS）
- 顔写真は撮影の演出のみで、画像は一切保存しません

## 1. Mac での開発・動作確認

```bash
npm install
npm run set-admin-password   # 管理画面パスワードのハッシュを生成
```

表示された `ADMIN_PASSWORD_HASH=...` を `.env` にコピーします（`.env.example` を `.env` にコピーして編集）。

```bash
cp .env.example .env
# .env を編集して ADMIN_PASSWORD_HASH を設定
npm start
```

`http://localhost:3000` を開くと打刻画面、`http://localhost:3000/admin/` で管理画面にアクセスできます。

## 2. タブレット (Termux) へのデプロイ

1. Termux / Termux:Boot / Termux:API を F-Droid からインストール
2. Termux でパッケージを準備し、リポジトリを取得
   ```bash
   pkg update && pkg install nodejs-lts git termux-api
   git clone <このリポジトリのURL>
   cd <リポジトリ>
   npm install
   npm run set-admin-password
   cp .env.example .env   # ADMIN_PASSWORD_HASH を設定
   sh scripts/termux-start.sh
   ```
3. Chrome で `http://localhost:3000` を開き、「ホーム画面に追加」でアイコン化

## 3. 止まらない運用（常時稼働の設定）

タブレットを置きっぱなしにすると「サーバーが Android に殺される」「画面が消えてブラウザが凍結する」
の2つで止まる。次の3層すべてを設定しておくこと。**どれか1つだけでは止まる。**

### (1) サーバーを殺させない — Termux 側

- 起動は必ず `scripts/termux-start.sh` を使う（`npm start` を直接叩かない）。
  このスクリプトが `termux-wake-lock` で CPU の停止を防ぎ、落ちても5秒後に自動再起動する。
- Android の設定 → アプリ → Termux → バッテリー → **「制限なし」**（バッテリー最適化の対象外）にする。
- 端末は**常時充電**にしておく（充電が切れると何をしても止まる）。
- 自動起動: `~/.termux/boot/start-kintai.sh` を作成し実行権限を付与。
  ```bash
  #!/data/data/com.termux/files/usr/bin/sh
  sh ~/<リポジトリ>/scripts/termux-start.sh
  ```
  ```bash
  chmod +x ~/.termux/boot/start-kintai.sh
  ```
- 見張り役の登録（推奨）: Android にプロセスグループごと殺されると再起動ループも消えるため、
  Android 自身のジョブスケジューラから 15 分ごとに生死確認させる。**1回だけ**実行する。
  ```bash
  termux-job-scheduler --job-id 1 --period-ms 900000 --persisted true \
    --script /data/data/com.termux/files/home/<リポジトリ>/scripts/termux-guard.sh
  ```
  登録内容の確認は `termux-job-scheduler --pending`、解除は `termux-job-scheduler --cancel-job 1`。

### (2) 画面を消させない — Android 側

打刻画面は Screen Wake Lock API で画面スリープを抑止するが、OS 設定でも二重に押さえる。

- 開発者向けオプション → **「充電中は画面をスリープにしない」** を ON
- 設定 → ディスプレイ → 画面消灯 を最長（30分など）に設定
- 設定 → セキュリティ → **画面固定（アプリ固定 / ピン留め）** を ON にし、
  打刻画面を固定してキオスク状態にする
- 画面焼き付けが気になる場合は、消灯を許して**ロック画面から復帰して使う運用でもよい**。
  復帰時にアプリ側が自動でリロード・再接続するため、打刻データは失われない。

### (3) 画面が固まっても自力で戻る — アプリ側（実装済み）

- 画面スリープ抑止（Screen Wake Lock、復帰時に自動で取り直し）
- 15〜20秒ごとの `/api/health` 監視。切断中は赤帯を表示し、復旧したら自動で復帰
- 3分以上サーバーが落ちていた場合は復帰時に画面を自動リロード
- スリープ・タブ凍結で1分以上時計が飛んだら自動リロード（日付跨ぎのズレ防止）
- 打刻フローが2分固まったら自動でトップ画面に戻す（カメラのハング対策）

### 日常の運用チェック

- 朝の始業前に打刻画面をタップし、時計が現在時刻を指していることを確認する
- 画面上部に赤帯が出ていたら Termux を開き直し、`sh scripts/termux-start.sh` を実行する
- 週1回は端末を再起動する（Termux:Boot 設定済みなら自動で復帰する）
- 動きが怪しいときは `~/kintai.log` の末尾を見る: `tail -50 ~/kintai.log`

## 4. 月次データの出力

管理画面の「勤怠記録」タブ →「月次データ出力」パネルで、年を `‹ ›` で送り、月をタップして選ぶ。
スタッフを選べばその人だけ、「全員」なら全員分を出力する。時給の初期値は 1800 円。

### Excelダウンロード（給与計算用・推奨）

`勤務時間_2026年9月.xlsx` が 2 シート構成で出力される。縦が日付、横がスタッフのマトリクス。

1. **勤務時間帯** — 各セルに `09:00-18:00 (9h)`。1日に複数回勤務した日は `09:00-12:00, 13:00-18:00 (8h)`、
   退勤を押し忘れた日は `08:00-未打刻` と入る
2. **勤務時間** — 各セルは時間の数値だけ。最下部に「合計勤務時間」「給与(時給×時間)」、
   右端に日ごと・全体の「総計」列が入る

給与は `=合計勤務時間 * $A$1` の数式で入っているので、**シート「勤務時間」の A1 の時給を書き換えれば
全員の給与が再計算される**。時間は 8:30 → 8.5 の小数表記なので、そのまま単価を掛けられる。

### CSVダウンロード

1ファイルに2ブロック入る。Excelを使わず素のデータが欲しいとき用。

1. **日別勤務明細** — スタッフ名 / 日付 / 曜日 / 出勤 / 退勤 / 勤務時間(時:分) / 勤務時間(時間) / 備考
2. **月合計** — スタッフごとの 勤務日数 / 勤務回数 / 合計勤務時間 / 退勤打刻なしの件数（最後に「全員合計」行）

### 共通の集計ルール

- 夜勤など日をまたぐ勤務は**出勤した日の月**に計上する（9/30 22:00 出勤 → 10/1 6:30 退勤 は9月分）
- 退勤打刻が無い勤務は時間を 0 として扱い、Excelは `未打刻`、CSVは備考「退勤打刻なし」で分かるようにしている
- その月に1度も出勤していないスタッフは列に出さない

## 5. バックアップ

DB は `data/kintai.sqlite3` の1ファイルのみ。週1回程度、USBメモリ等へコピーしてください。
管理画面のCSVエクスポートも簡易バックアップとして利用できます。

## ディレクトリ構成

```
server/          Express サーバー・API・DB(CSV/Excel生成を含む)
public/          打刻画面（トップ）
public/admin/    管理画面
data/            SQLite DB（gitignore 対象）
scripts/         管理者パスワード設定スクリプト
```
